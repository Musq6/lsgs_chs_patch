Lenin Street Geek Shop 简体中文补丁  v1.0
==========================================

适用版本：Lenin Street Geek Shop Demo（Unity 6000.0.58f2）
汉化范围：界面 3,055 条 + 对话 17,897 条，覆盖率 100%


一、安装
--------
把本文件夹里的所有内容复制到游戏根目录，与 "Lenin Street Geek Shop.exe" 同级。

复制完成后应该是这样：

    Lenin Street Geek Shop\
      ├─ Lenin Street Geek Shop.exe
      ├─ winhttp.dll                 ← 新增
      ├─ doorstop_config.ini         ← 新增
      ├─ .doorstop_version           ← 新增
      └─ BepInEx\                    ← 新增
           ├─ core\...
           ├─ config\lsgs.zh.patch.cfg      （首次启动自动生成）
           └─ plugins\LSGS_Chinese\
                ├─ LSGS_Chinese.dll
                ├─ zh_ui.csv                 界面译文
                └─ zh_lines.csv              对话译文

启动游戏即为中文。不需要任何额外运行库，不会修改游戏本体文件。


二、卸载
--------
删除以下四项即可，游戏恢复原样：

    winhttp.dll
    doorstop_config.ini
    .doorstop_version
    BepInEx\


三、首次启动会慢约 20 秒（正常现象）
------------------------------------
补丁启动时要把全部 3,073 个汉字光栅化成字形图集，这段时间游戏窗口会「未响应」，
属于正常过程，等它自己过去即可。之后每次启动仍会走这一步（约 20 秒）。

日志里对应的记录：

    [预热] 3073 字 ok=True 缺字=0 图集=1 张 耗时=21709ms


四、配置
--------
路径：BepInEx\config\lsgs.zh.patch.cfg

**重要：修改配置必须在游戏完全关闭时进行。**
游戏运行期间改这个文件，退出时会被内存里的旧值覆盖回去。

[General]

    ForceChinese = true         启动即切换中文。设 false 则保持游戏原语言
    AddLanguageOption = true    在设置界面的语言下拉框里增加「中文」

[Font]

    EnableFont = true           挂载中文字体。设 false 中文会全部变成方框
    FontFile =                  指定字体文件（相对 plugins\LSGS_Chinese\ 的路径）
                                留空则自动从系统字体目录挑选中文字体
    FontRegister = none         【必须保持 none】改成 all 会导致主线程卡死
    FontStatic = true           预热完成后把字体转为静态图集
    MaterialMode = clone        复用游戏现成字体的材质与着色器
    VerboseSwap = false         排查用：每次替换字体都写日志
    UseExistingFont =           诊断用，保持留空

关于字体：补丁会自动扫描 C:\Windows\Fonts，优先选用单体 .ttf 中文字体
（等线 Deng.ttf 等），没有才退回 .ttc 字体集合。Windows 系统自带字体已足够。

想换成自带的字体：把 ttf 放进 plugins\LSGS_Chinese\fonts\，然后设
    FontFile = fonts/你的字体.ttf


五、修改译文
------------
两个 CSV 都是 UTF-8 编码，两列：主键, 中文。

    zh_ui.csv      key,zh    界面文本（键名来自游戏内 LocaliztionSyncData）
    zh_lines.csv   id,zh     对话文本（id 为 Yarn 行 ID）

直接加行、改行，保存后重启游戏生效。没翻到的条目会自动回落原语言，
不会显示成键名或空白。

注意：对话的说话人前缀必须是「半角冒号 + 空格」，例如 `列昂: 你好`。
用全角「：」会导致角色名识别失败，人物立绘不显示。


六、自检
--------
日志文件：BepInEx\LogOutput.log

正常启动应看到：

    [词库] UI 3055 条 / 对话 17897 条
    [补丁] ... OK        （共十项左右，全部 OK）
    [语言] 已切换到中文
    [字体] 使用 deng.ttf（已含验证）
    [预热] 3073 字 ok=True 缺字=0 图集=1 张

如果出现「[词库] UI 0 条」，说明 zh_ui.csv 格式被破坏（例如被表格软件改过列），
补丁内置了容错，会尝试从其它列回读，但建议重新解压一份覆盖。


七、已知问题
------------
1. 极少数跑龙套角色（约 820 行台词，如「阿尔卡沙」「牛郎」「娜塔莉亚」）在游戏里
   本来就没有配置角色卡，名字以默认颜色显示、没有立绘图标——原版同样如此。

2. 中文普遍比原文短，个别按钮和文本框会显得偏空，不影响点击。

3. 译文为机翻 + 人工校对，绝大多数日常对话读起来自然，但少量俚语、双关、
   俄式文化梗可能仍有生硬之处。可以在 CSV 里自行润色。

4. 有 16 行对话在原版数据里英文为空、只有俄文，已按俄文补译，个别句子
   可能比原文略简。

5. 游戏原生字体中没有汉字，补丁是通过运行时字体替换实现的。极个别界面如果
   出现字形异常，请把日志和截图反馈。


八、兼容性
----------
- 只替换文本与字体，不修改游戏资源文件，不影响存档
- 与存档系统、Steam 云同步无交互
- 如果游戏本体更新导致类名变化，补丁会跳过对应功能并在日志里记录「失败」，
  不会导致游戏无法启动
